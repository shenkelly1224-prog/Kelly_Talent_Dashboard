## 2. 产品概述

### 2.1 产品定位

面向企业 HR 的标准化人才盘点工具。通过「绩效 × 潜力」双维度模型，结合离职风险预警和继任计划管理，帮助企业系统性识别高潜人才、预警流失风险、搭建管理梯队。

**核心价值主张：**
- 用数据替代直觉：基于事实与行为观察的问答式评估，减少主观偏差
- 用流程保障公平：两步校准机制确保评估结果跨团队可比
- 用工具提升效率：单文件离线运行、数据不出本地，隐私与便捷兼得

### 2.2 产品原则（设计宪法）

本项目遵循「0 时间成本、低运维、可复用、副业收入」的产品原则：

1. **纯前端单文件**：零依赖、零框架、零后端 → 可离线分发、零运维
2. **数据不出本地**：所有数据存浏览器 localStorage，不联网 → 隐私合规、客户放心
3. **可复制售卖**：一份 HTML 文件即产品，无运营成本
4. **AI 优先开发**：非技术背景也能迭代，逻辑全在 `engine.js`

### 2.3 目标用户

| 用户角色 | 职责 | 使用场景 |
|----------|------|----------|
| 项目主理人（HRBP） | 配置、导入、分发、校准、报告 | 全流程主导 |
| 评估人（业务管理者） | 评估下属绩效/潜力/风险/准备度 | 在分发文件中完成评估 |
| 一号位（CEO/GM） | 审阅 | 看校准会汇报与报告 |

### 2.4 业务目标

1. **识别高潜**：九宫格定位高绩效+高潜力人才（目标占比前 20%）
2. **预警风险**：独立评估离职风险，提前干预保留核心人才
3. **搭建梯队**：为关键岗位建立接班人地图（含跨团队视角）
4. **落地发展**：高潜人才有明确的 IDP 发展计划

                             │
              ┌──────────────┴──────────────┐
              ▼                              ▼
    ┌──────────────────┐          ┌──────────────────┐
    │   评估人入口      │          │  项目主理人入口   │
    │ (选姓名+密码验证) │          │  (密码验证)       │
    └────────┬─────────┘          └────────┬─────────┘
             │                             │
             ▼                             ▼
    ┌──────────────────┐     ┌─────────────────────────┐
    │   评估工作台      │     │     五大模块             │
    │ · 人才评估        │     │ 设置 / 基础信息 /        │

**关键设计：**

- 评估人在项目主理人分发的文件（含数据与配置）中直接评估，无需手动导入

## 4. 评估框架（核心产品逻辑）

### 4.1 九宫格定位模型

**横轴：绩效（自动计算）**

| 绩效等级 | 对应分数 | 评级档位 |
|----------|----------|----------|
| 卓越 | 5 | 高绩效 ≥ 4.0 |
| 优秀/超越目标 | 4 | 高绩效 ≥ 4.0 |
| 达成目标 | 3 | 中绩效 2.5-3.9 |
| 待提升 | 2 | 低绩效 < 2.5 |

**三年加权公式：**
```
绩效分 = 前年 × 20% + 去年 × 30% + 今年 × 50%
```
（仅有 1 年数据 → 该年权重 100%；完全无数据 → 标注缺失，不入九宫格）

> 注：以上等级名称、分数线、权重均可在「配置向导」中按企业实际自定义。

**纵轴：潜力（评估人填写）**

四维度「是否」题，每题答"是"得 1 分。高潜 / 中潜分数线可在配置中调整（默认高潜 >= 12，中潜 >= 8，对应 4 维度 x 4 题 = 16 题）。

**九宫格输出：**

| | 高绩效 | 中绩效 | 低绩效 |
|---|---|---|---|
| **高潜力** | ⭐ 星星人才 | 💡 潜力之星 | ⚠️ 关注对象 |
| **中潜力** | 🔧 核心人才 | 📦 基石人才 | 📉 基础人才 |
| **低潜力** | 📉 基础人才 | 📉 基础人才 | 📉 基础人才 |

**对应管理动作：** 星星（重点培养、快速晋升、启动 IDP）、潜力之星（提升绩效、项目历练）、核心（激励保留、加薪奖金）、基石（稳定贡献）、关注（分析原因）、基础（PIP、岗位调整）。

### 4.2 离职风险评估（独立维度，不纳入九宫格）

**设计原则：** 离职风险单独评估保留风险，避免单一负面指标污染人才定位。

**ELT 观察题（默认 8 题，可配置）：** 每题「是」=5 分。涵盖职业倦怠、工作热情、团队参与、绩效下滑、上下级关系、离职倾向、外部机会、个人因素等。

**HRBP 数据类指标（可选）：** 项目主理人可导入 HRBP 维度的风险分（司龄、薪酬竞争力、晋升停滞等），与 ELT 观察分综合计算。

**风险等级（默认阈值，可配置）：**
**风险等级（百分比阈值，自动适配题目数量）：**
- 综合满分 = 题目数 x 5 x 2（ELT 端 + HRBP 端各一份）
- 高风险：综合分 >= 满分的 50%（取整）
- 中风险：满分的 25% <= 综合分 < 满分的 50%
- 低风险：综合分 < 满分的 25%

> 注：主理人在配置向导中增减离职风险题目后，阈值自动按新题目数重算。

### 4.3 继任计划

针对关键岗位评估接班人准备度：
- **Ready Now**：可立即接任
- **1-3 年**：1-3 年内可接任
- **3 年+**：长期培养对象

含跨团队接班意愿（跨区域 / 家庭因素 / 跨职能 / 专业转管理），支持校准会跨团队调配讨论。

## 5. 功能规格

### 5.1 设置模块

| 功能 | 说明 |
|------|------|
| 配置向导 | 三步配置：基本信息 / 绩效规则 / 题库设置。配置嵌入分发文件 |
| 数据导入导出 | 员工 CSV 导入、分发文件生成、评估 CSV 回收汇总、HRBP 风险 CSV（可选）、JSON 备份 / 恢复、清空数据 |
| 操作日志 | 记录所有操作（时间 / 动作 / 角色），最多 200 条 |
| 账户与密码 | 修改密码、重置（清空数据重新设置） |

### 5.2 基础信息模块

| 功能 | 说明 |
|------|------|
| 评估人员配置 | 评估人（被评估人的直属上级）独立管理：工号、姓名、岗位、部门、层级、密码。CSV 批量导入 + 模板下载 |
| 人员管理 | 名册查看 + 新增 / 编辑 / 删除（CRUD）+ 搜索。填三年绩效自动算分，下拉选直属上级，删除时清理关联评估并重建汇报关系 |
| 人员管理 CSV | 支持 CSV 批量导入员工数据 + 模板下载 |
| 关键岗位管理 | 关键岗位列表，新增时输入岗位名称可自动匹配现任负责人（从评估人和被评估人员中搜索）。CSV 批量导入 + 模板下载 |

### 5.3 盘点评估模块

| 功能 | 说明 |
|------|------|
| 人才评估 | 潜力评估、离职风险、跨团队接班意愿、发展建议、接班准备度。评估人视图按下属筛选 |
| 九宫格 | 全员绩效×潜力分布，支持拖拽校准 |
| 继任计划 | 关键岗位接班人地图，可搜索添加 / 删除候选人 |
| 校准会议 | 标签页：九宫格校准（可拖拽）/ 风险清单 / 跨团队接班；支持导出校准后报告 |
| 盘点批次记录 | 保存历史快照（人数 / 星星 / 潜力 / 核心 / 高风险），支持查看与趋势对比 |

### 5.4 分析洞察模块

人才仪表盘：人才分类分布、绩效分布、离职风险预警（高/中/低）、部门人才对比。

### 5.5 发展行动模块

IDP 发展计划：基于校准后高潜人才（星星 / 潜力之星 / 核心 / 有接班准备度）的表格。展开行可看评估录入的优势 / 待提升 / 评估建议，填写发展目标、行动措施、导师、衡量标准。支持导出 CSV。

## 6. 数据流与协作机制

```
项目主理人                           评估人（多人）
    │                                    │
    │ 1. 配置向导                         │
    │ 2. 导入员工 CSV                     │
    │ 3. 生成分发文件 ──────────────────> │ 4. 打开分发文件（含数据+配置）
    │                                    │ 5. 评估下属
    │ <──────────── 6. 导出评估 CSV ──────│
    │ 7. 回收 CSV 汇总                    │
    │ 8. 九宫格 / 校准会 / 报告 / IDP     │
    │                                    │
```

**无服务器协作的实现：** 通过文件传递（邮件 / 即时通讯）+ 角色入口隔离，实现「多人协作」而不需要后端。

## 7. 技术架构

### 7.1 技术选型

| 维度 | 选型 | 理由 |
|------|------|------|
| 语言 | 原生 JavaScript + HTML + CSS | 零依赖、零框架、零构建工具链 |
| 数据存储 | 浏览器 localStorage | 离线、隐私、零运维 |
| 分发方式 | 单 HTML 文件 | 双击即用，可邮件发送 |
| 构建 | Node 脚本（`build_platform.js`） | 合并 CSS + HTML + engine.js |

### 7.2 源码结构

- `src/engine.js`：**唯一逻辑源码**（~2450 行，包含默认配置、数据模型、角色门、导航、CSV 解析、所有视图渲染器）
- `src/build_platform.js`：构建脚本（含基础 CSS + UI/UX 精修层 CSS_POLISH + 页面骨架 BODY）
- `dist/index.html`：构建产物（成品，Vercel 部署入口）

### 7.3 数据键

| localStorage 键 | 内容 |
|-----------------|------|
| `trp_config_v1` | 配置 |
| `trp_data_v1` | 人员、评估人、汇报关系、岗位、批次、IDP、日志 |
| `trp_assessments_v1` | 评估结果 |
| `trp_dev_pwd` | 项目主理人密码 |
| `trp_guide_done_evaluator` / `trp_guide_done_hrbp` | 新手引导已完成标记 |

## 8. 产品化与售卖策略

### 8.1 形态
纯工具售卖：一份脱敏的 HTML 文件 + 配置向导，客户买去导入自己的数据即可用。

### 8.2 定制化能力（已内置）
- 组织信息、绩效等级与分数线、加权权重
- 潜力维度与题库（可替换为客户的胜任力模型）
- 离职风险题库
- 团队归属列名

### 8.3 差异化
相较市面全栈 SaaS：零运维、数据不出本地、可买断、即买即用、无订阅负担。

## 10. 后续路线（规划中）

以下为已讨论但**暂不实现**的方向，记录以备后用：

- 增加更多基于现有数据的可视化（趋势对比、漏斗分析等）
- 评估人导出更多视图（个人评估摘要）
- 报告模板多样化（不同汇报对象的报告样式）
- 国际化 / 多语言界面

**明确不做的方向（与产品原则冲突）：**
- ❌ AI 预测类功能（需后端、需数据上传、运维成本高、与「数据不出本地」冲突）
- ❌ SaaS 化（运营成本高、与市面产品难差异化）
- ❌ 复杂权限管理系统（违背「轻量」原则，当前角色入口已足够）
