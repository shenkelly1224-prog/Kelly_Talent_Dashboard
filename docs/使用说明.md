# Talent Review 人才盘点平台 · 使用说明

感谢使用本工具。本工具是一个单一平台，项目主理人（HR）和评估人（业务管理者）各有独立入口。打开 talent_review_platform.html 或访问线上地址即可使用，数据只存在本地浏览器，不经过任何网络传输。

## 二、第一次使用：配置向导（重要）

首次以项目主理人身份进入时，会自动弹出配置向导。配置会被嵌入分发文件，保证所有人用同一套标准。之后可在「设置 → 配置向导」随时修改：

**基本信息**：组织名称、项目名称、层级选项（默认 N-1/N-2/N-3）、团队归属列名。

**绩效规则**：绩效等级与分数（默认 S/A/B/C/D）、三年加权权重、高/中绩效分数线。

**题库设置**：潜力维度与题目（默认 4 维度 x 4 题 = 16 题）、离职风险题目（默认 8 题，每题"是"=5 分）。

配置向导中的绩效等级、层级等设置会自动关联到人员管理、评估表等所有模块的下拉选项。

## 三、完整操作流程

**项目主理人操作：**

1. 以项目主理人身份进入，完成配置向导
2. 在「数据导入导出」中依次导入三类 CSV：评估人员、被评估人员、关键岗位（每类均可下载模板）
3. 也可在「基础信息」模块逐条新增或编辑
4. 在「数据导入导出」中点击「生成分发文件」，下载含数据的 HTML 文件
5. 通过邮件发送给各评估人

**评估人操作：**

1. 打开收到的 HTML 文件，选择「我是评估人」
2. 选择自己的姓名，输入 4 位密码进入
3. 逐个评估下属：潜力维度答题、离职风险答题、填写优势/待提升/发展建议、接班准备度
4. 每评估完 1 人点击「保存评估」，再点击「导出当前评估」下载 CSV
5. 把所有 CSV 文件发回给项目主理人

**项目主理人汇总与校准：**

1. 在「数据导入导出」中回收评估结果 CSV（可多选上传）
2. 进入「九宫格」查看绩效 x 潜力分布，可拖拽调整
3. 进入「继任计划」查看关键岗位接班人地图
4. 进入「校准会议」查看九宫格/继任/IDP/风险清单/跨团队意愿，导出校准后报告
5. 如有 HRBP 风险数据，在「数据导入导出」中导入（可下载评分引导模板）

## 四、常见问题

**Q：CSV 导入报错说找不到列？**

A：工具兼容多种列名叫法（如"层级/职级/级别"）。如仍有问题，可下载对应模板确认字段名。

**Q：导入评估人后岗位和层级不显示？**

A：请确认导入顺序：先导入评估人员 CSV，再导入被评估人员 CSV。导入员工时不会覆盖已有的评估人信息。

**Q：浏览器缓存清理后数据丢了？**

A：数据只存在本地浏览器。项目主理人可在「数据导入导出」中导出 JSON 备份。评估人建议每评估完 1 人导出 CSV。

**Q：绩效等级和我们公司不一样怎么办？**

A：在配置向导中自定义绩效等级名称和对应分数即可。

**Q：如何重播新手引导？**

A：在「数据导入导出」页面底部有「重新播放新手引导」按钮，侧边栏底部也有「新手引导」入口。

**Q：如何重置全部数据？**

A：在「数据导入导出 → 账户与密码」中点击「重置」，会清空所有本地数据并回到首次进入状态。

## 五、数据安全提醒

- 所有数据只存在本地浏览器，不经过任何网络传输
- 评估结果属于员工敏感信息，请妥善保管，禁止外传
- 校准后的报告含个人评价，分发范围请严格限制在知情范围内
